## L10 未见目录（catalogue）泛化被高估（本轮最重要限制，已降级结论）

  强制目录不相交只剩 553/221/641 个 dev 行，不足以支撑任何估计。

**0.807 / 0.718 / 0.790**；所有置信区间改为**按目录聚类**自助法（EXP-0019），CI 宽度最多放大 **2.955 倍**，
9/9 主对比仍不含 0；另记 GEE 稳健标准误最大为朴素值的 **7.33 倍**，说明此前朴素 p 值过于乐观。
遗留真实风险：在没有独立目录集合的数据上，事前预测能力的下界仍未被证明。

## L1 因变量的构念是"排序器相对"的，不是客观"路由失败"
主因变量定义为"冻结 BM25(k1=1.4,b=0.4) 未把任一金标注工具放入 top-3"。EXP-0011 显示：换成 description-only 排序器后，两个定义的正例集合只重叠 **3.4%（Kimi-K2）/ 6.6%（OSS）/ 10.6%（Qwen3）**。虽然预测器在替代定义下仍达 AUROC 0.7945–0.8297（可迁移），但"失败"不能解释为工具系统本身必然失败。→ 正文用"lexical unreachability / 词面不可达"表述，避免"agent routing failure"。

## L2 金标注非穷尽（H4 已检验，结论为"不成立"）

原判断"因变量可能被金标注稀疏性夸大"已由 EXP-0014 + EXP-0015 定量检验并被否证：
dev 上最严格确定性等价规则仅改判 **0.68% / 3.09% / 7.10%** 的正例（预注册阈值 ≥10% 未达到），
事前模型 dev AUC 不降反微升（0.8233→0.8236 / 0.8294→0.8305 / 0.7951→0.7996）；
随机抽取该规则命中的工具对并连指令一起人工判读 40 例，**真正等价者为 0**
（32 例同服务器兄弟工具、6 例跨系统、2 例无法判定、3 例本轮未读并已如实记为缺失）。
因此上述改判率只是标签噪声的**上界**。

遗留限制（不掩饰）：(a) 等价判据仍是词面/结构式，不是语义式，在无 API 约束下无法引入更好的判定器；
(b) 人工判读由本文作者一人完成，**没有第二标注者，因此没有 κ**，属可复核性弱点；
(c) 宽松规则把流行率压到 0.0004、AUC 压到 0.4146，说明"用词面相似度做等价"本身会摧毁构念，
这一负结果同样报告在附录 A6。
Toucan 论文 §3.1 自述 `target_tools` 不穷尽；ToolEX（2609.08327）报告同类数据集上 67.9% 的子查询存在功能等价替代、30–47% 的表观增益属评测伪影。我们**尚未**实现等价工具重标注（EXP-0013 计划中），故所有结论目前是"在下发的金标注集合下"。这是本篇最大的已知敞口。

## L3 合成查询的生态效度
问题文本由 5 个查询模型从工具集正向合成，指令与目标工具描述的词面重叠部分由生成过程决定；且"更长指令→更低失败率"（OR 0.854–0.901）很可能部分是生成效应（长查询枚举了更多工具名）。因此不得推断真实用户的表述行为。真实人类指令对照（AgentNet）尚未执行。

## L4 结构排除带来的范围限制
fail@3 分析中 dev 有 **25.0%–47.6%** 的查询因目录规模 ≤3 被剔除（该层 fail@3 恒为 0）。结论范围限于"候选工具数大于 k 的目录"。

## L5 教师效应与框架效应混杂
三个 config 同时更换教师模型、生成框架与质量过滤（Toucan §3.1），跨 config 复现只能说明"不依赖单一生成设定"，不能分离为模型能力效应。

## L7 p 值分辨率与显著性陷阱
