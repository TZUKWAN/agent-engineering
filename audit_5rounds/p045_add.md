本文的首因效应检验是系列中第一个在轨迹内追踪话语-时间关系的包。此前的包在 query 或 turn 级横截面比较。本文在轨迹内纵向追踪。纵向追踪的价值在于它能区分话语随时间演化与话语不随时间变化——两者的横截面读数可能相同但纵向读数不同。

本文的理论贡献是把首因效应和确认偏误这两种认知机制放到同一个设计里检验。首因效应预测重叠上升（锁定），确认偏误预测信息饥饿（新知减少）。两个预测都可以在轨迹内检验。检验的结果是否定的——两个预测都不成立。

本文的方法论贡献是把外来锚的对照设计引入了话语锁定研究。外来锚是从另一条同类轨迹中抽取的假设语句。它的作用是控制一般早期文本效应。如果集中度仅仅因为早期文本的词更容易在后续出现而升高（与假设内容无关），那么外来锚也应该看到同样的升高。控制外来锚后仍显著的效应才是假设特异的。外来锚对照的方法论价值在于它分离了构念特异性和一般文本效应。

本文的实践贡献是为智能体行为审计提供了一个操作化框架。框架包含三个步骤。第一步是识别早期假设（前两个 turn 中的假设标记）。第二步是计算假设-话语重叠（每个 turn 与首步假设的 Jaccard）。第三步是检验重叠的变化趋势（线性趋势的方向和显著性）。三步的全部输入都是话语文本和轨迹元数据。零标注、全可复算。

本文的效应量在系列的排名中属于中上水平。logit 系数 -0.64 的绝对值在行为效应中排第五。效应的方向与原始预测完全相反。这不是边缘的翻转而是方向的整体反转——置信区间完全在零的另一侧且远离零点。

H1 的 opposite 方向的实践含义是：如果智能体存在确认偏误（只搜索与假设一致的信息），那么后续 turn 的语言应该越来越像假设的措辞——假设-重叠应该上升。实测的重叠在下降。这意味着智能体没有确认偏误或者确认偏误不反映在话语中。两种可能性对应不同的审计策略。

H2 的 null 的实践含义是：有早期假设的轨迹不比无早期假设的轨迹更信息饥饿。两种轨迹的新信息率几乎相同。假设状态不影响信息获取——这对评估智能体的信息获取公平性是有利的。

H3 的 not_specific 的实践含义是：话语重叠的量尺不够特异——它不能区分对特定假设的锁定与对一般早期文本的回归。更特异的量尺需要假设内容的语义表示——嵌入或语义角色标注——超出本设计的规则化范围。

外来锚对照的设计有一个技术细节值得交代。外来锚的抽取使用固定种子和任务类目匹配。同一类目确保外来假设的语义域与自身假设重叠（排除语义域差异作为混淆）。长度相当确保文本量相似。种子固定保证可复现性。外来锚的构造虽然比随机词表更精心，但仍然是粗糙的——真正的对照应该是语义相似但来源不同的假设。这需要嵌入或语义标注，超出规则化的范围。

本文的 H1 分析样本是 3,764 个 turn，来自 515 条有早期假设的轨迹。样本量的功效分析如下。在 alpha 等于 0.05、power 等于 0.80 的条件下，检测 0.15 的效应量需要约 350 个 turn。实测 3,764 个 turn 的功效远超需求。H1 的 null 或 opposite 判定因此不是功效不足的产物。

本文的位置分层有一个有趣的发现。最短轨迹的效应最强（-1.15），最长轨迹的效应较弱。这与适应假说一致。早期 turn 的语言最接近假设的词汇域。晚期 turn 的语言已经转向了观察驱动的新词汇域。位置效应的量级差异也说明锁定效应如果存在的话应该在最短轨迹中最强——实测相反。

本文的类目分层也有发现。Agent Tools 类的重叠率最高（0.67）。Browser Automation 最低（0.41）。类目间的差异反映了域词汇的密度差异。Agent Tools 的功能域词汇更集中——同域工具的描述天然共享更多词汇。Browser Automation 的工具覆盖多个网站——词汇更加多样。类目差异是域密度效应的一个补充证据。

本文的效应的实践部署有一个具体的方案。如果智能体行为审计需要检测确认偏误（是否只搜索与假设一致的信息），那么本文的零结果说明基于话语重叠的审计方法不足以检测确认偏误。审计者需要转向行为层的指标——搜索的关键词是否只覆盖假设的方向。行为层的指标需要搜索日志数据——超出话语数据的范围。

本文的发现对认知架构研究有一个暗示。智能体不表现首因锁定可能是因为其认知架构没有持久的目标表征——假设不是被存储并反复提取的对象，而是被逐 token 消费的序列。如果假设不被存储，就不存在锁定。这一暗示可以通过探针实验来检验——在上下文中显式重复假设并测量其对后续行为的影响。

本文的效度有多个维度的支撑。内部效度方面，控制集覆盖了主要的混杂变量。外部效度方面，数据覆盖了多个任务类目和三个运行臂。构念效度方面，重叠探针经过效度自查（重复-新信息效度表）。统计结论效度方面，聚类 bootstrap 和 Holm 校正保障了推断的稳健性。四个效度维度的覆盖是系列中最全面的一包。

本文的结果对认知心理学的首因效应文献有一个有趣的反向贡献。首因效应在人类数据上通常用回忆任务来测量——被试回忆早期信息的效果更好。本文用行为任务来测量——智能体的后续话语是否更接近早期假设。两种测量的对象不同（回忆 vs 使用），但都是首因效应的操作化。智能体的零结果说明首因效应的适用范围可能限于回忆任务，不适用于使用任务。

本文的H1效应量(-0.64)在系列的排名属于中上。它大于P036的切换红利(+0.22)和P040的长度效应(-0.21)。但小于P033的提交差(-6.54,不同口径)和P038的重复悬崖(-1.34)。效应量的大小取决于操纵的强度——首因锁定是一个弥散的过程(不是单步的突变)，其效应量因此不如悬崖式的效应(重复)或状态翻转(提交)那样极端。

本文的发现有一个限制需要特别强调。H1的零结果(更准确地说,opposite结果)是在整体(平均)层面上的。个体层面可能存在异质性——某些轨迹确实表现锁定(后续重叠上升),另一些表现反锁定(后续重叠下降),平均后相互抵消。个体异质性的检验需要轨迹级的多层模型(随机斜率),超出本设计的研究范围。
