## What this does not claim

Neither table re-derives an interval; that is `round2_statistical_consistency.py` and `round2_interval_audit.py`. A record stating a unit is not proof that its count equals the number of distinct values of that unit in the frame it read - checking that would mean re-reading the frames themselves, which is what `round2_corpus_remeasurement.py` does for counts and row totals. Where the two sides disagree, the code side is the one to believe, and the disagreement is a defect to fix in the design, not to paper over here.
