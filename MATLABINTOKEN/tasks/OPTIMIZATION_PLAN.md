# 三篇论文优化方案总览

## 方案概述

将现有5项研究重组为**3篇独立可发表的论文**，每篇完成必要的实验优化和方法论升级。

## 论文重组结构

| 论文 | 来源 | 核心问题 | 投稿目标 |
|------|------|---------|---------|
| **论文A** | 研究3（语用结构类型学） | 用户指令是否存在可识别的语用结构类型？不同类型的执行效应如何？ | 《当代语言学》《外语教学与研究》 |
| **论文B** | 研究1+研究2（验证+约束融合） | 用户指令中的两类"边界性言语行为"——验证（终止边界）与约束（行动边界）——如何影响执行？ | 《现代外语》《语料库语言学》 |
| **论文C** | 研究5+研究4（风险路径+推理链融合） | 提示风险如何通过推理-指令对齐度影响任务结果？ | 《外语电化教学》《中文信息学报》 |

## 共性优化原则

1. **随机种子**：所有随机过程固定为 `42`
2. **样本口径**：统一使用 `data/processed/analysis_data.parquet`（22,811条），步骤数据用 `data/interim/paper04/steps.parquet`（421,453步）
3. **输出规范**：
   - 代码 → `src/optimization/paperA|B|C/`
   - 结果 → `results/optimization/paperA|B|C/`
   - 每个数值结果同时输出 `.json` + `.csv`
4. **复现要求**：所有代码可独立运行，依赖明确列出
5. **不作弊**：不得用因变量定义自变量，不得事后挑选显著结果

## 依赖关系

```
论文B（无依赖，可先做）
    ↓
论文A（需要论文B的句法特征作为LCA输入）
    ↓
论文C（需要论文A的类型标签 + 论文B的特征作为输入）
```

建议执行顺序：B → A → C
