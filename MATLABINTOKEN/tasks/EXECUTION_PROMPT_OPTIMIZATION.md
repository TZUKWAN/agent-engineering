## 论文B：边界性言语行为（验证+约束融合）

**任务文档**：`tasks/paperB_boundary_speech_acts.md`

### 要点
1. **验证标准**：二分（has_completion_criteria）+ 连续（verification_density）
2. **约束词**：四分类（禁止型/保留型/要求型/限制型）+ 密度计算
3. **验证效应**：Logistic回归 + 负二项回归 + 终止阶段分析 + 非线性检验 + 位置分析
4. **约束效应**：全局倒U检验 + 条件性倒U（难度/长度/子任务调节）+ 子类型异质性 + 稳健性
5. **融合新增**：验证vs约束的直接对比（联合模型、边际贡献、协同效应）
6. **效度验证**：聚合效度、区分效度、已知群组效度

### 核心假设
- H1a-c：有验证标准 → 完成率↑、步数↓、终止冗余↓
- H2：验证密度线性正相关（非线性不显著）
- H3：验证位置无影响
- H4：有约束词 → 完成率↑
- H5：约束密度无全局倒U
- H6-H8：条件性倒U（难度/长度/子任务调节）
- H9：子类型最优密度不同

### 交付物
- `src/optimization/paperB/` — 全部分析代码
- `results/optimization/paperB/` — 所有JSON/CSV/PNG结果
- `results/optimization/paperB/report.md` — 完整结果报告

## 论文A：语用结构类型学（LCA升级版）

**任务文档**：`tasks/paperA_pragmatic_typology.md`

### 要点
1. **特征升级**：用spaCy（en_core_web_lg）提取11个句法/语用特征（祈使句谓语、情态标记、宣告性谓语、完成体、篇章连接词、论元结构、T单位、从句密度、依存树深度、命名实体）
2. **效度检验**：新句法特征 vs 原关键词特征的聚合效度与区分效度
3. **LCA重跑**：用poLCA（R包）或带Bootstrap的GMM，提供LRT检验和稳定性检验
4. **路径稳定性构念效度**：已知群组效度验证（难度、完成状态、效率评分）
5. **类型差异分析**：完成率、步数、错误/冗余比例、路径稳定性（MANOVA）
6. **控制显性度后的独立效应**
7. **任务难度调节**
8. **稳健性检验**：分平台、特征集对比、样本量敏感性

### 核心假设
- H1：存在3-5种可识别的语用结构类型
- H2：不同类型完成率差异显著
- H3：不同类型路径稳定性差异显著（核心发现）
- H4：控制显性度后类型仍显著（χ²似然比检验）
- H5：任务难度调节类型效应

### 交付物
- `src/optimization/paperA/` — 全部分析代码
- `results/optimization/paperA/` — 所有JSON/CSV/PNG结果
- `results/optimization/paperA/report.md`

## 论文C：提示风险与推理-指令对齐度（风险路径+推理链融合）

**任务文档**：`tasks/paperC_prompt_risk_pathway.md`

### 要点
1. **修复循环论证**：剔除所有用task_completed或步骤标签定义的"推理错误"指标
2. **构建对齐度指标**：纯文本比对指令与推理文本（约束对齐、验证对齐、分解对齐、对象对齐）
3. **推理链类型融入**：检验提示风险是否诱发不同推理链类型（卡方+多项Logistic）
4. **中介路径重建**：提示风险 → 对齐度 → 执行错误 → 任务完成（Bootstrap 2000次）
5. **推理链类型调节**：不同推理链类型下，对齐度→执行错误路径强度是否不同
6. **效度验证**：对齐度的已知群组效度

### 核心假设
- H1：提示风险指数与推理-指令对齐度负相关
- H2：对齐度与执行错误负相关
- H3：执行错误与任务完成负相关
- H4：提示风险通过对齐度→执行错误形成间接路径（中介效应显著）
- H5：提示风险总效应不显著，但间接效应显著
- H6：完成标准缺失和验证要求缺失是影响对齐度最强的风险
- H7：推理链类型调节对齐度→执行错误的路径

### 核心红线
**构建对齐度指标时，绝对不能使用** task_completed、last_step_correct、last_step_redundant。只能用指令文本和推理文本的纯文本比对。

### 交付物
- `src/optimization/paperC/` — 全部分析代码
- `results/optimization/paperC/` — 所有JSON/CSV/PNG结果
- `results/optimization/paperC/report.md`
