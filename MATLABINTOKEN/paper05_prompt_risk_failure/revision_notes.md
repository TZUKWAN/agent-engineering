# 论文五修改说明

## 主要决策

1. **数据集选择**：以 AgentNet 为主数据集，与前三篇论文保持一致，便于复用提示语用特征变量。
2. **风险特征操作化**：继承前三篇的二元语用特征，扩展构建 10 项风险特征。将“约束缺失”与“约束过密”分别定义为约束密度等于 0 与大于 5%，避免二者互补导致信息冗余。
3. **验证要求缺失**：与“完成标准缺失”区分，前者基于是否含明确验证动词（check/verify/confirm/test 等），后者基于更广义的完成标准词。
4. **错误指标**：采用规则型代理指标，明确其为过程证据而非人工精细标注。
5. **统计路径**：使用 OLS + Logistic 回归组合，配合 bootstrap 顺序中介分析，明确结论为观察性统计路径，非因果证明。

## 已知局限

- 推理错误指标中部分指标发生率较低（如约束遗漏、任务分解错误），可能导致综合指数由少数指标主导。
- 路径分析基于横断面数据，无法严格确立时间顺序。
- 未引入外部代码/工具智能体数据集进行稳健性检验。
