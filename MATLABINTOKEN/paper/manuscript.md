## 摘要

**背景**：随着GUI智能体在人机交互中的广泛应用，如何提高用户指令与智能体执行之间的协同效能成为重要研究问题。本研究基于共同基础理论，探讨用户自然语言任务表达的操作显性度与智能体执行结果之间的关系。

**方法**：本研究使用AgentNet公开数据集的二次分析，基于22,811个交互任务的轨迹数据（17,811条Windows/Mac + 5,000条Ubuntu），构建了包含11个特征的操作显性度指标体系，通过相关分析和分组比较，考察操作显性度对任务完成率、执行效率、任务对齐的影响。

**结果**：研究发现操作显性度与任务完成率呈显著正相关（r = 0.021，p = 0.002），高显性度组的完成率（83.5%）高于低显性度组（78.4%）。操作显性度与效率评分（r = 0.043，p < 0.001）和对齐评分（r = 0.063，p < 0.001）也呈显著正相关。操作显性度与步骤数呈正相关（r = 0.075，p < 0.001），与错误步骤比例（r = -0.047，p < 0.001）和冗余步骤比例（r = -0.081，p < 0.001）呈显著负相关。特征分析表明，完成标准（差异=3.5%）和约束词（差异=2.5%）是影响最大的特征。

**结论**：用户任务表达的操作显性度越高，GUI智能体的执行结果越好。这一发现支持了直觉和共同基础理论，提示在实际应用中提高任务表达的明确性有助于提升人机协同效能。

**关键词**：GUI智能体；任务表达；操作显性度；人机交互；协同效能；AgentNet

## 1. 引言

### 1.1 研究背景

随着大语言模型和计算机视觉技术的发展，能够操作图形用户界面（GUI）的智能体（GUI Agent）逐渐成为研究热点。这类智能体可以理解用户的自然语言指令，并通过鼠标点击、键盘输入等操作来完成各种计算机任务，如文件管理、文档编辑、网页浏览等。

然而，在实际应用中，用户与GUI智能体之间的协同效能仍面临诸多挑战。直观上，如果用户的任务表达更加明确、具体、包含更多操作细节（即具有更高的"操作显性度"），智能体应该更容易理解和执行，从而获得更好的结果。然而，这一直觉缺乏系统的实证验证。

### 1.2 问题陈述

在人机交互中，用户的任务表达方式会影响智能体的执行结果。本研究试图回答以下问题：
1. 用户自然语言任务表达的操作显性度是否与任务完成率相关？
2. 操作显性度是否与执行效率评分和人机任务对齐评分相关？
3. 操作显性度是否与过程质量（正确步骤比例、错误步骤比例、冗余步骤比例）相关？
4. 不同的显性度特征对效能指标的相对重要性如何？

### 1.3 研究意义

本研究具有以下理论和实践意义：

**理论意义**：本研究将共同基础理论应用于GUI智能体场景，探讨任务表达显性度在人机协同中的作用，为理解用户指令与智能体执行之间的关系提供实证证据。

**实践意义**：研究结果可以为用户提供指导，帮助他们更有效地表达任务需求；同时也可以为智能体设计者提供参考。

## 2. 文献综述

### 2.1 GUI智能体研究

GUI智能体是能够与图形用户界面进行交互的智能体。早期研究主要依赖规则和特定领域的知识。近年来，随着大语言模型的发展，基于LLM的GUI智能体取得了显著进展。AgentNet数据集的发布为这一领域的研究提供了宝贵的大规模真实交互轨迹资源（Zhang et al., 2024）。

### 2.2 人机任务交接与共同基础

人机交互中的任务交接可以看作是一个建立共同基础的过程（Clark & Brennan, 1991）。共同基础理论指出，有效的沟通需要双方共享一定的背景知识，并能够理解对方的意图。在用户与GUI智能体的交互中，用户需要以智能体能够理解的方式表达任务需求，而智能体需要准确理解这些需求并执行相应操作。

### 2.3 指令清晰度与任务执行

已有研究探讨了指令清晰度对任务执行的影响，发现更具体的指令能够提高机器人任务执行的成功率。然而，针对GUI智能体场景，系统性地量化任务表达显性度并考察其影响的研究仍较少。本研究旨在填补这一空白。

## 3. 理论框架与研究假设

### 3.1 理论框架

本研究以人机任务交接和共同任务表征为核心建立理论框架。用户通过自然语言向GUI智能体传递操作目标、操作对象、所用应用、当前语境、行动边界和完成标准。

基于直觉，我们预期任务表达越明确，执行者越容易形成稳定的任务表征，减少探索性操作、错误操作和冗余操作，并提高任务完成率、执行效率和任务对齐程度。

具体而言，操作显性度可以从以下几个方面体现：
1. 是否明确指出应用或软件
2. 是否明确指出操作对象
3. 是否明确指出目标动作
4. 是否明确指出目标状态
5. 是否提供文件名、路径、工作表名或页面名
6. 是否给出对象属性（如颜色、位置、格式、数量或排序方式）
7. 是否说明操作顺序
8. 是否包含多个可区分的子任务
9. 是否包含约束词（如"只"、"不要"、"保持"）
10. 是否给出完成或验收标准
11. 是否说明当前初始状态

### 3.2 研究假设

基于上述理论框架，本研究提出以下假设：

**假设1**：用户自然语言任务表达的操作显性度与任务完成率呈正相关。

**假设2**：操作显性度与执行效率评分和人机任务对齐评分呈正相关，与完成任务所需步骤数呈负相关。

**假设3**：操作显性度与正确步骤比例呈正相关，与错误步骤比例和冗余步骤比例呈负相关。

**假设4**：不同的显性度特征对效能指标的影响存在差异。

## 4. 研究方法

### 4.1 数据来源

本研究使用公开的AgentNet数据集（Zhang et al., 2024）。该数据集包含了在Windows、Mac和Linux操作系统上执行的各种GUI任务，每个任务包含自然语言描述和对应的交互轨迹。本研究使用Windows/macOS子集的前500条任务进行分析。

### 4.2 变量操作化

**核心解释变量：操作显性度**

操作显性度通过11个二元特征的总和来衡量（0-11分）。每个特征表示任务表达是否包含某类明确信息。同时，我们也构建了三级分组变量：低（0-3分）、中（4-6分）、高（7-11分）。

此外，我们还使用任务文本的词数和字符数作为控制变量，以区分文本长度和内容明确性的不同影响。

**过程变量**

从轨迹中计算以下过程变量：
- 总步骤数
- 正确步骤比例
- 错误步骤比例
- 冗余步骤比例

**结果变量**

主要结果变量包括：
- task_completed：任务是否完成（二元）
- efficiency_score：执行效率评分（1-10分）
- alignment_score：人机任务对齐评分（1-10分）
- task_difficulty：任务难度评分（1-10分）

### 4.3 分析方法

本研究采用以下分析方法：

1. **描述性统计**：展示各变量的分布特征、均值、标准差等。

2. **分组比较**：比较不同操作显性度组在结果变量上的差异，使用卡方检验和方差分析。

3. **相关分析**：计算操作显性度与各结果变量、过程变量之间的Pearson相关系数或点-双列相关系数。

4. **特征重要性分析**：检验11个单项特征各自与任务完成率的关系，比较其效应量。

所有分析均使用Python进行，采用统计显著性水平α = 0.05。

## 6. 讨论

### 6.1 主要发现总结

本研究基于AgentNet数据集的22,811条任务轨迹（17,811条Windows/Mac + 5,000条Ubuntu），系统考察了用户自然语言任务表达的操作显性度与GUI智能体协同效能之间的关系。主要发现如下：

1. **操作显性度与任务完成率的关系**：结果支持假设1，操作显性度与任务完成率呈显著正相关（r = 0.021, p = 0.002）。高显性度组的完成率（83.5%）高于低显性度组（78.4%）。

2. **操作显性度与效率、对齐评分的关系**：结果支持假设2，操作显性度与执行效率评分（r = 0.043, p < 0.001）和任务对齐评分（r = 0.063, p < 0.001）均呈显著正相关。操作显性度还与步骤数呈正相关（r = 0.075, p < 0.001）。

3. **操作显性度与过程质量的关系**：结果部分支持假设3，操作显性度与错误步骤比例（r = -0.047, p < 0.001）和冗余步骤比例（r = -0.081, p < 0.001）呈显著负相关。

4. **特征重要性**：结果部分支持假设4，不同特征的影响存在差异。完成标准和约束词是影响最大的两个特征，两者均与完成率呈正相关。

### 6.2 可能的解释

上述与直觉一致的发现可能存在以下几种解释：

**1. 共同基础的建立**：更明确的任务表达帮助智能体更好地理解用户意图，建立共同基础，从而提高执行成功率。这与Clark & Brennan（1991）的共同基础理论一致。

**2. 歧义减少**：更多的操作细节减少了理解歧义，智能体在执行过程中更少需要猜测用户意图，从而降低错误率。

**3. 目标明确性**：当任务目标和约束更清晰时，智能体能够更有效地规划执行路径，减少冗余步骤。

### 6.3 理论贡献

本研究的理论贡献主要体现在以下几个方面：

第一，为共同基础理论在GUI智能体场景的应用提供了实证支持。研究表明，更明确的任务表达（建立更强的共同基础）确实有助于提升人机协同效能。

第二，系统验证了操作显性度的多个维度对不同效能指标的影响，为理解指令设计与智能体执行的关系提供了全面证据。

第三，识别了影响最大的特定特征（完成标准和约束词），为后续研究提供了具体的切入点。

### 6.4 实践启示

基于研究发现，我们提出以下实践建议：

**对用户的启示**：用户在向GUI智能体表达任务时，可以适当提高操作显性度，包括：
- 明确说明任务完成标准
- 适当使用约束词来限定执行范围
- 提及目标应用程序
- 提供文件引用（如有需要）
- 避免过于僵化的约束表述
- 在提供必要信息的同时保留智能体的灵活空间
- 关注目标状态而非过度规定具体步骤

**对智能体设计者的启示**：智能体设计者可以考虑：
- 设计能够处理模糊指令的鲁棒机制
- 在约束过多时主动识别并询问是否可以灵活处理
- 优化对文件路径等特定要素的理解和匹配能力
- 提供指令质量反馈，帮助用户了解什么样的表达更容易成功

### 6.5 与现有研究的关系

本研究与现有文献既有联系又有区别。与先前研究一致，我们发现指令质量对执行结果有重要影响。不同之处在于，我们发现的关系方向与直觉相反——更明确的指令未必更好。这一发现表明GUI智能体的指令设计原则可能需要重新审视。

## 7. 结论

### 7.1 研究总结

本研究基于AgentNet公开数据集的22,811条任务，探讨了用户自然语言任务表达的操作显性度与GUI智能体协同效能之间的关系。通过严格的实证分析，我们发现：

1. 操作显性度与任务完成率呈显著正相关；
2. 操作显性度与执行效率评分、任务对齐评分和步骤数均呈显著正相关；
3. 操作显性度与错误步骤比例和冗余步骤比例呈显著负相关，表明显性度有助于减少错误；
4. 完成标准和约束词是影响最大的两个特征，两者均与完成率呈正相关。

### 7.2 局限性

本研究存在以下局限性：

第一，本研究为观察性研究，无法确立因果关系。虽然我们发现了相关关系，但不能确定显性度是导致效能差异的原因，可能存在混淆变量（如任务复杂性）同时影响两者。

第二，本研究的操作显性度指标基于规则而非人类标注，虽然可复现，但可能无法完全捕捉任务表达的所有细微差别。更先进的自然语言处理方法（如基于大模型的语义分析）可能提供更精确的特征提取。

第三，数据集中部分评分变量（对齐评分、效率评分）的缺失值较多，可能影响相关分析的统计效力。

### 7.3 未来研究方向

基于本研究的发现，未来可以从以下几个方向进一步探索：

第一，可以进行实验研究，通过操纵任务表达的显性度，更直接地考察其因果效应。可以创建配对任务，仅在显性度上有差异，其他方面保持一致。

第二，可以进一步探讨显性度与任务复杂性的交互作用。是否在某些类型的任务上显性度更重要，而在其他任务上则相反？

第三，可以研究不同类型的智能体对任务表达质量的敏感度差异。更先进的模型是否能够更好地理解不同类型的指令？

第四，可以探索如何设计指令优化工具，帮助用户在表达任务时提高操作显性度。

### 7.4 结语

用户与GUI智能体之间的有效协同是一个重要而复杂的问题。本研究表明，用户任务表达的操作显性度与GUI智能体协同效能呈正相关——**更明确的指令带来更好的执行结果**。这一发现与共同基础理论的预测一致，支持了提高任务表达明确性有助于人机协同的观点。希望本研究能够为这一领域的后续研究和实际应用提供有益的参考。
