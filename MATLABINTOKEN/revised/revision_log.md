# 修改日志：从 GUI-Agent 特征回归论文到任务型交互智能体实证论文

## 总体修改策略

本次修改的核心目标是将三篇原以“GUI-Agent 指令特征回归”为主的论文，重构为围绕“任务型交互智能体”的高水平人机交互/语用学实证论文。修改遵循以下原则：

1. **统一理论对象**：三篇论文统一使用“任务型交互智能体”作为理论对象，明确通用执行链路；
2. **明确经验边界**：所有论文均说明结论基于 AgentNet GUI 轨迹，不随意推广；
3. **重新定位研究问题**：Paper 03 聚焦任务构型，Paper 02 聚焦行动边界，Paper 01 聚焦终止判准；
4. **弱化不当因果表述**：将“导致”“证明机制”“直接影响”改为“相关”“关联”“预测关系”“过程证据”等；
5. **强化过程指标**：除任务完成率外，重点报告执行步数、错误比例、冗余比例、路径稳定性等过程指标；
6. **增加真实示例与稳定性检验**：Paper 03 补充每类真实指令示例与轻量级稳定性检验；Paper 01 补充终止阶段新指标；Paper 02 补充条件性非线性分析；
7. **规范参考文献**：删除或修正未引用、未核实或疑似不存在的文献，补充真实经典文献。

## Paper 03：语用结构类型学论文

### 标题变更
- **原**：提示表达的语用结构类型学：基于潜类别分析的 GUI-Agent 指令分类研究
- **新**：任务型交互智能体用户指令的语用结构类型及其执行效应——基于 AgentNet 交互轨迹的潜类别分析

### 主要修改
1. **理论框架重构**
   - 引入“任务型交互智能体”定义与通用执行链路；
   - 明确 AgentNet GUI 轨迹作为经验边界；
   - 将研究问题重新表述为“用户如何通过自然语言把任务组织成可执行的交互结构”。

2. **保留并强化五类框架**
   - 保留：对象/文件丰富型、极简型、动作约束型、动作导向型、约束验证型；
   - 每类补充 3 条真实指令示例，包括原文、中文解释、命中特征、后验概率与任务结果。

3. **结果解释重心转移**
   - 从“完成率差异”转向“执行路径稳定性差异”；
   - 重点讨论错误比例、冗余比例、最长连续错误步数、动作转换率等过程指标；
   - 不再深入讨论完成标准终止机制或约束密度倒 U 形问题。

4. **LCA 稳定性检验**
   - 补充 8:2 train/test split（ARI = 0.958）；
   - 补充 k=4/5/6 比较；
   - 补充 5 次 bootstrap（ARI M=0.859, SD=0.164），但因次数不足明确标注为“待补强”。

5. **新增局限说明**
   - 规则特征效度未经过人工标注验证；
   - 观察性数据、未重新运行智能体；
   - 同一 task_id 多次尝试导致路径分析样本量解释需谨慎。

## Paper 01：完成标准/终止判准论文

### 标题变更
- **原**：用户指令中验证显性度对 GUI 智能体执行终止的影响
- **新**：完成标准作为终止判准：用户指令验证显性度与任务型交互智能体执行效率——基于 AgentNet 交互轨迹的实证研究

### 主要修改
1. **核心论点升级**
   - 将主线从“验证显性度影响完成率”升级为“完成标准作为停止线索如何关联终止效率”；
   - 明确完成标准、验证动作和目标状态为智能体提供外显终止判准。

2. **新增终止阶段过程指标**
   - 从 `analysis_data.parquet` 和 `steps.parquet` 计算：
     - 最后 25% 步骤冗余比例
     - 最后 25% 步骤错误比例
     - 最终步骤是否冗余/错误
     - 未完成任务中的异常短轨迹率
   - 比较结果：含完成标准的任务在最后 25% 冗余（5.55% vs 6.37%）、错误（12.18% vs 13.40%）及异常短轨迹率（1.19% vs 2.47%）上均更低。

3. **样本量口径统一**
   - 22,811：原始任务尝试数；
   - 20,484：回归分析有效样本（剔除关键变量缺失）；
   - 2,869：`has_completion_criteria == 1` 的原始子集；
   - 2,684：含完成标准且进入回归的样本；
   - 2,512：可定位验证关键词位置的样本。

4. **验证类型分布处理**
   - 明确动词指令式（V1）占 82.9%，状态目标式（V2）与条件验证式（V3）样本极少；
   - 将 H2（类型差异）降为探索性分析，不做强推断。

5. **密度倒 U 形降级**
   - 验证密度非线性分析改为补充分析；
   - 明确未发现稳健倒 U 形关系。

6. **新增局限说明**
   - 观察性研究无法建立因果；
   - 规则化验证关键词标注可能误分类；
   - 未区分应用领域与模型版本。

## Paper 02：约束负荷/条件性非线性论文

### 标题变更
- **原**：用户提示中约束密度对 GUI 智能体任务完成率的非线性影响
- **新**：约束何时成为负荷：任务型交互智能体用户指令中约束密度的条件性非线性效应——基于 AgentNet 交互轨迹的实证研究

### 主要修改
1. **核心论点重构**
   - 将中心结论从“全局倒 U 形”改为“条件性非线性效应”；
   - 提出约束的双重作用：适度约束提供边界，过量约束形成负荷；
   - 强调不存在普遍最优约束密度，效应取决于任务难度与指令复杂度。

2. **两阶段/三阶段分析框架**
   - **Stage 1**：是否包含约束（全样本 Logistic）；
     - 结果：OR = 1.165，p < 0.001；
   - **Stage 2**：约束密度效应（仅含约束任务子样本）；
     - 结果：全局二次项不显著（b₂ = 0.016，p = 0.083）；
   - **Stage 3**：条件性非线性（按任务难度、指令长度、任务复杂度分组）；
     - 高难度任务：b₂ = –0.039，p = 0.019，拐点 ≈ 1.93%；
     - 长指令任务：b₂ = –0.041，p = 0.025，拐点 ≈ 1.69%；
     - 高复杂度任务（has_multiple_subtasks=1）：b₂ = –0.045，p = 0.006，拐点 ≈ 1.87%。

3. **Johnson-Neyman 风格简单斜率/曲率**
   - 沿任务难度取值范围计算斜率与曲率；
   - 曲率显著为负区域大致对应任务难度 ≥ 6。

4. **边界条件讨论**
   - 低约束：行动边界不足，探索空间大；
   - 适度约束：减少歧义，缩小行动空间；
   - 高约束：规划与验证负荷增加，可能产生约束冲突；
   - 高难度/长指令任务：更容易出现约束过载。

5. **新增局限说明**
   - RCS 3 节点模型未收敛；
   - 约束关键词规则无法识别隐含约束与复杂否定；
   - 高密度观测稀少，统计功效受限。

## 2026-09-26 · 五轮审计 R1：数据完整性与统计修正（重大修订）

**发现的问题**
1. AgentNet 原始轨迹文件（ubuntu_5k + win_mac_18k）共 22,625 行，但唯一 `task_id` 仅 22,532 个，与官方
   `meta_data_merged.jsonl` 的 22,532 条一致；93 个重复 id 中 76 个在 `task_completed`/`alignment_score` 等
   标签上互相冲突。按 `task_id` 合并时多对多膨胀使 `analysis_data` 达 22,811 行（+186 笛卡尔积行）。
2. `src/08_fit_models.py`、`src/09_robustness_checks.py` 的 `safe_corr` p 值近似公式在负相关时给出 p>1
   （顶层试点表 `table3_main_results.csv` 曾出现 p≈2.0），正相关时亦失真。
3. `paper05` 的 `model1`/`model2` 表缺 se/p 列而正文引用了 p 值；`model3` 存在准完全分离迹象未作说明；
   "多子任务倒 U"等引用在管道中无对应产出。

**采取的修复**
- 全部解析/建库脚本（`03_parse_trajectories.py`、`reanalyze_full_data.py`、`paper04/05 01_parse_agentnet.py`）
  增加 task_id 去重（step_num 匹配优先，否则保留末次出现），去重审计落盘 `data/interim/*/dedup_audit.json`；
  `06_build_analysis_data.py` 补原始文本列透传与唯一性断言。
- `safe_corr` 改用 `scipy.stats.pearsonr` 精确 p 值；全量重跑 08–12 号脚本与 paper01–05 全部管道。
- `paper05 04_path_analysis.py` 的 model1/model2 表补 se/t/p；`paper02 02_quadratic.py` 补 Stage-1（约束有无）
  与 Stage-2（约束子样本）模型；`paper02 04_moderation.py` 补多子任务分割（此前正文引用无管道支撑）。
- 五篇正文（`revised/paper01–03_rewritten.md`、`paper04/05 manuscript.md`）全部数字按重跑输出更新，
  并在各文头部加"数据修订说明"；`merged_report.md`/`merged_report_unified.md` 已重新生成。

**实质性结论变化**
- paper02 Stage-1：约束有无与完成率的"显著正相关"（OR=1.165, p<0.001）在去重后不再成立
  （OR=0.947, p=0.459），判定为重复记录造成的假象；Stage-3 调节效应（高难度/长指令/多子任务的倒 U 形）
  方向与显著性不变。
- paper05 模型 3 中 risk_index 直接效应由显著（OR=1.11, p=0.012）变为不显著（OR=1.075, p=0.117），
  与"风险经由错误间接起效"的路径论述一致。
- paper01/03/04 各统计量数值平移，定性结论不变。
