# Paper 02 修订版补充表格说明

本目录包含论文《约束何时成为负荷：任务型交互智能体用户指令中约束密度的条件性非线性效应》中使用或引用的全部补充表格。

| 文件名 | 内容 |
|--------|------|
| `table1_constraint_taxonomy.md` | 约束表达类型学定义与关键词 |
| `table2_constraint_distribution.csv` | 约束类型分布 |
| `table3_density_descriptives.csv` | 约束密度描述性统计 |
| `table4_stage1_stage2_models.csv` | Stage 1 与 Stage 2 Logistic 回归结果 |
| `table5_conditional_effects.csv` | 任务难度、指令长度、子任务数量的条件效应 |
| `table6_subtype_analysis.csv` | 约束子类型二次模型结果 |
| `table7_robustness_checks.csv` | 稳健性检验（AIC/BIC/伪 R²） |
| `table8_stage2_full_coefficients.csv` | Stage 2 完整系数表 |
| `table9_johnson_neyman_simple_slopes.csv` | Johnson-Neyman 风格的简单斜率与曲率 |
| `table10_process_outcome_models.csv` | 探索性过程结果模型 |
| `additional_analysis.json` | 新增计算结果（Stage 1/2、条件模型、简单斜率）的原始 JSON |

所有数值均来自 `data/processed/analysis_data.parquet` 与 `src/paper02/` 分析脚本，未编造任何系数、AIC 或 p 值。
