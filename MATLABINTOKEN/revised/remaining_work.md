# 剩余工作与待补强事项

## 1. 数据与特征层面

### 1.1 规则特征的人工效度验证
- **现状**：三篇论文中的二元特征（如 `has_completion_criteria`、`has_constraint_words`、11 个 LCA 特征）均基于关键词与正则规则自动提取，未经过人工标注的 precision、recall、F1 或 Cohen's κ 验证。
- **待做**：
  - 从每类特征中随机抽取 200–400 条指令；
  - 由两名以上标注者独立判断特征是否真正表达对应语用功能；
  - 计算 precision、recall、F1 和 Cohen's κ；
  - 对误分类案例进行错误分析，优化规则或改用 LLM-based 分类器。

### 1.2 task_id 聚类稳健标准误
- **现状**：当前回归模型未考虑同一 `task_id` 多次尝试可能带来的相关性。
- **待做**：在 Logistic / 负二项 / OLS 模型中使用按 `task_id` 聚类的稳健标准误（cluster-robust SE），重新评估 p 值和置信区间。

### 1.3 按 task_id 去重的稳健性检验
- **现状**：路径分析中步级指标按 `task_id` 聚合后映射到多次尝试，可能 inflate 有效样本量。
- **待做**：
  - 构建按 `task_id` 去重的子样本；
  - 在去重样本上重新运行关键模型，比较结果是否一致。

### 1.4 排除极端长轨迹
- **现状**：当前分析未系统排除极端长轨迹（如 total_steps > 99th percentile）。
- **待做**：报告极端值剔除前后的结果稳定性。

## 2. Paper 03 专属待补强

### 2.1 LCA 稳定性与模型选择
- **现状**：已进行轻量级 train/test split（ARI = 0.958）和 5 次 bootstrap，但次数不足。
- **待做**：
  - 进行 200 次以上 bootstrap，每次 30 次随机启动；
  - 计算后验概率分布的稳定性指标（如 mean posterior probability within assigned class）；
  - 报告 k=4/k=5/k=6 的完整拟合统计量与类别解释性对比；
  - 如可能，使用 R `poLCA` 或 `Mplus` 进行确认性 LCA，并计算 Lo-Mendell-Rubin LRT。

### 2.2 跨平台/跨任务类型验证
- **现状**：类型学基于 AgentNet GUI 数据，未在 Web Agent、Code Agent 等环境中验证。
- **待做**：在跨平台数据中拟合同一 LCA 模型，比较类别结构与条件概率矩阵的稳定性。

## 3. Paper 01 专属待补强

### 3.1 终止阶段指标的精细化
- **现状**：已计算最后 25% 步骤冗余/错误比例、最终步骤状态、异常短轨迹等指标。
- **待做**：
  - 识别终止前的“查看/确认/保存/提交”类动作（需更细粒度的步骤动作标签，当前数据中可能缺失）；
  - 计算终止前连续重复动作次数；
  - 区分“过早终止”（异常短轨迹）与“过晚终止”（长轨迹但失败）。

### 3.2 验证类型标注的精细化
- **现状**：V2（状态目标式）与 V3（条件验证式）样本极少，只能做探索性分析。
- **待做**：
  - 使用依存句法分析或 LLM 进行更精细的验证言语行为分类；
  - 扩大状态目标式与条件验证式的识别覆盖面。

## 4. Paper 02 专属待补强

### 4.1 RCS 与 GAM 非线性模型
- **现状**：RCS 3 节点模型未收敛，仅报告了二次模型结果。
- **待做**：
  - 尝试不同节点数（4–5 节点）或惩罚样条（GAM）重新拟合；
  - 报告样条模型的有效自由度、EDF 与拟合曲线。

### 4.2 Bootstrap 拐点置信区间
- **现状**：拐点置信区间基于 Delta 方法，可能受小样本影响。
- **待做**：使用 bootstrap（如 1,000 次）重新估计高难度/长指令子样本的拐点及其置信区间。

### 4.3 Johnson-Neyman 区间可视化
- **现状**：已报告沿任务难度取值范围的简单斜率/曲率表。
- **待做**：绘制 Johnson-Neyman 风格图，明确约束密度效应由正转负或曲率显著为负的任务难度阈值区域。

### 4.4 约束语义角色标注
- **现状**：约束仅按禁止/保留/要求/限制四类关键词分类。
- **待做**：标注约束的对象、动作、条件等语义角色，检验“约束谁/在什么条件下/做什么”的异质性。

## 5. 共同待补强

### 5.1 因果推断设计
- **现状**：三篇论文均为观察性二次分析，无法确立因果。
- **待做**：
  - 设计对照实验，系统操纵指令的语用结构、约束密度或完成标准；
  - 或采用倾向得分匹配、双重差分、工具变量等因果推断方法在观察数据中加强因果证据。

### 5.2 跨数据集复现
- **现状**：结论仅基于 AgentNet。
- **待做**：在其他 GUI/Web/Code Agent 数据集（如 Mind2Web、WebArena、SWE-bench）中复现核心发现。

### 5.3 生成 Word 版修订论文
- **现状**：已完成三篇修订 markdown 文件及配套图表表格。
- **待做**：如需要，可将修订后的 markdown 转换为 Word（.docx）格式。当前环境未安装 pandoc，可使用 python-docx 手工转换或安装 pandoc 后通过 `pandoc revised/paper0X_revised.md -o revised/paper0X_revised.docx` 批量生成。

| 中 | Paper 02 RCS/GAM/bootstrap 拐点 | 支撑条件性非线性结论 |
