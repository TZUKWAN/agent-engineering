# 约束何时成为负荷：任务型交互智能体用户指令中约束密度的条件性非线性效应——基于 AgentNet 交互轨迹的实证研究

## 摘要

用户指令中的约束表达（如禁止、保留、要求、限制）是任务型交互智能体提示工程的重要杠杆，但其密度与任务完成率的关系并非简单的“越多越好”。本研究基于 AgentNet 大规模 GUI 轨迹数据（原始样本 *N* = 22,811），以语用学与认知负荷理论为框架，将约束密度重新界定为一种“条件性边界资源”：适度约束能够压缩动作空间、降低歧义；过高密度则会转化为规划、验证与冲突检查的认知负荷。研究采用两阶段 Logistic 回归、二次 Logistic 回归、交互效应模型与限制性立方样条等多元方法，系统考察约束密度对任务完成率的非线性影响及其边界条件。结果显示：第一阶段模型表明，包含约束词与任务完成率呈显著正相关（OR = 1.165，95% CI [1.075, 1.262]，*p* < 0.001）；第二阶段在仅含约束任务子样本（*N* = 1,261）中，全局二次项未达显著（*b*₂ = 0.016，*p* = 0.083）。进一步的条件模型发现，任务难度与指令长度显著调节密度—完成率关系：高难度任务呈现显著倒 U 形（*b*₂ = –0.039，*p* = 0.019），最优密度约 1.93%；长指令任务亦呈显著倒 U 形（*b*₂ = –0.041，*p* = 0.025），最优密度约 1.69%。探索性分析还显示，包含多个子任务的任务中约束密度同样呈显著倒 U 形（*b*₂ = –0.045，*p* = 0.006），拐点约 1.87%。冗余步数比在中等密度时达到峰值，提示约束可能通过“探索—验证”权衡影响执行效率。研究强调，约束密度的效应不存在普适最优值，而取决于任务复杂度、信息长度与信息需求；实践上，对高难度、长指令或多子任务任务，建议将约束密度控制在 1.7%–1.9% 左右。

**关键词**：任务型交互智能体；用户指令；约束密度；条件性非线性效应；认知负荷；任务难度；AgentNet

## Abstract

Constraint expressions in user instructions—such as prohibitions, requirements, and restrictions—are an important lever for prompting task-oriented interactive agents, yet their density is not simply "the more, the better." Drawing on pragmatics and cognitive load theory, this study reconceptualizes constraint density as a *conditional boundary resource*: moderate constraints compress the action space and reduce ambiguity, whereas excessive constraints increase planning, verification, and conflict-checking load. Using the large-scale AgentNet GUI trajectory dataset (raw *N* = 22,811), we examined the nonlinear association between constraint density and task completion with a two-stage logistic regression, quadratic logistic regression, interaction models, and restricted cubic splines. In Stage 1, the presence of constraint words was positively associated with completion (OR = 1.165, 95% CI [1.075, 1.262], *p* < 0.001). In Stage 2, restricted to tasks containing constraints (*N* = 1,261), the global quadratic term was not significant (*b*₂ = 0.016, *p* = 0.083). Conditional models, however, revealed significant moderation by task difficulty and instruction length: high-difficulty tasks showed a significant inverted-U (*b*₂ = –0.039, *p* = 0.019) with an optimal density around 1.93%, and long-instruction tasks showed a similar pattern (*b*₂ = –0.041, *p* = 0.025) with an optimal density around 1.69%. Exploratory analyses further showed a significant inverted-U for tasks with multiple subtasks (*b*₂ = –0.045, *p* = 0.006), turning point ≈ 1.87%. Redundant-step ratio peaked at moderate density, suggesting an exploration–verification trade-off. The findings underline that there is no universal optimal constraint density; its effect depends on task complexity, instruction length, and information need. For high-difficulty, long, or multi-subtask instructions, we suggest keeping constraint density near 1.7%–1.9%.

**Keywords**: task-oriented interactive agent; user instruction; constraint density; conditional nonlinear effect; cognitive load; task difficulty; AgentNet

## 1. 引言

### 1.1 研究背景与问题

近年来，以大语言模型（Large Language Model, LLM）为核心控制器的任务型交互智能体（task-oriented interactive agent）在网页浏览、桌面办公、移动操作与跨应用工作流等场景中展现出强大潜力（Li et al., 2024; Yang et al., 2022; Yuan et al., 2023）。这类系统通过解析自然语言指令，自主规划并执行一系列界面操作，从而完成从信息检索、文件编辑到复杂多步骤任务执行的广泛目标。用户指令作为人机协作的“语言入口”，其信息结构、显式程度与约束精确度直接影响智能体的行为轨迹与最终成效（Lasecki et al., 2013; Liang et al., 2020）。

在指令设计中，约束表达（如“不要……”“必须……”“只能……”“保持……不变”）是一种常见却尚未被充分理解的语用手段。从直觉上看，约束通过限定可接受动作集合来提升智能体输出的精确性；然而，约束是否越多越好？当约束密度超过某一阈值时，是否会因规划、验证与冲突消解成本上升而反而降低完成率？这一问题的答案对提示工程（prompt engineering）、智能体接口设计与用户指令撰写规范均具有重要价值。

既有文献多将约束视为二元特征（有/无），或将其纳入更宽泛的“指令明确性”框架中讨论（Goedert et al., 2013; Schatz, 2003）。少量研究开始关注约束的语义类型，但对其密度（density）的剂量—反应关系（dose–response relationship）缺乏系统检验。本研究的核心问题是：**用户指令中的约束密度如何调节任务型交互智能体的动作空间？在什么条件下约束发挥边界作用，又在什么条件下转化为认知负荷？**

### 1.2 研究边界：AgentNet GUI 轨迹的适用性

本研究以 AgentNet 公开数据集中的图形用户界面（GUI）轨迹为 empirical 基础（Zhang et al., 2024）。AgentNet 记录了智能体在真实桌面与网页应用环境中执行用户指令的完整操作序列，包括点击、输入、滚动、窗口切换等低层动作。因此，本文所讨论的“任务型交互智能体”特指以 GUI 操作为边界、以自然语言指令为输入的通用型数字智能体，而非纯对话式问答系统或机器人控制智能体。这一边界有助于明确结论的适用范围：研究发现主要面向需要多步界面操作、动作空间庞大且部分可观测的任务场景。

需要进一步说明的是，AgentNet 数据属于观测性轨迹数据：研究者只能观察到用户“写下了什么指令”以及智能体“最终是否完成”，无法观测用户撰写指令时的真实意图、任务领域知识或应用类型等潜在混淆因素。因此，本文所有结论均应在“关联性”而非“因果性”的框架下解读。约束密度与任务完成率之间的统计关联，可能同时受到任务复杂度、用户表达能力、应用领域难度等未测量变量的影响。

### 1.3 核心论点

本研究的核心论点是：约束在任务型交互智能体用户指令中具有**双重角色**。一方面，适度约束能够减少目标歧义、压缩搜索空间、降低规划分支数，从而提升完成概率；另一方面，当约束密度过高时，智能体需要额外的计算与推理资源来检查约束一致性、处理约束冲突、在局部可行解之间进行权衡，这会增加认知与计算负荷，最终可能抵消边界带来的收益。因此，约束密度与任务完成率之间的关系更可能呈现一种**条件性非线性模式**，而非普适的线性或全局倒 U 形规律。具体而言：

- **低密度**：约束不足，动作空间过大，目标边界模糊，智能体易产生冗余探索；
- **中密度**：约束提供清晰边界，歧义降低，完成率提升；
- **高密度**：约束数量超过智能体的规划与验证容量，冲突风险上升，完成率下降。

更重要的是，这一非线性关系的拐点与曲率取决于任务情境。高难度任务、长指令任务以及包含多个子任务的任务，其信息需求更高、规划深度更大，因而更容易因约束过载而受损；简单任务或短指令任务则对约束密度的容忍区间更宽。下文将基于 AgentNet 数据对上述理论预期进行实证检验。

## 2. 理论基础与研究假设

### 2.1 语用学视角：合作原则与关联理论

从语用学角度看，用户指令本质上是一种以行动达成为目的的言语行为（speech act）（Austin, 1962; Searle, 1969）。Grice（1975）提出的合作原则（Cooperative Principle）指出，成功交际需遵循量的准则（信息量适中）、质的准则（真实可信）、关系准则（内容相关）与方式准则（表达清晰）。在 GUI 指令中，约束表达是方式准则与量的准则共同作用的产物：它通过明确“不能做什么”“必须做什么”来降低歧义，但过量的约束又可能违反量的准则，造成信息冗余。

Sperber 与 Wilson（1995）的关联理论（Relevance Theory）进一步强调，语境效果的获取需要付出认知加工成本；听话者（或信息处理系统）会在认知投入与语境收益之间进行权衡。将这一框架迁移到人机场景可推知：智能体在解码指令时，需将每条约束纳入规划与验证；当约束密度超过一定阈值，新增的语境收益可能无法抵消递增的认知与计算成本，从而表现为绩效下降。Yeung（2016）在工作指令与培训研究中提出的“过犹不及”假说（too-much-of-a-good-thing）也支持这一非线性预期。

### 2.2 认知负荷与边界条件框架

认知负荷理论（cognitive load theory）为理解约束密度的条件效应提供了另一视角。Sweller（1988）指出，人类工作记忆容量有限，当外部信息结构超出加工容量时，学习或问题解决绩效会下降。类比到智能体系统，尽管 LLM 在推理阶段并不受限于人类工作记忆，但其规划与验证模块仍受上下文长度、注意力分配与冲突消解能力的约束。因此，高密度约束可能通过以下机制增加“负荷”：

1. **规划负荷**：每条约束都需被纳入动作序列生成，约束越多，可行动作组合越复杂；
2. **验证负荷**：执行过程中需反复确认当前动作是否违反任一约束；
3. **冲突消解负荷**：当多条约束相互冲突时，智能体需进行优先级排序或折中推理；
4. **信息检索负荷**：长指令中的高密度约束会稀释关键目标信息，增加语义解析难度。

基于上述理论，本研究将约束密度的效应置于**边界条件**（boundary conditions）框架下：不存在放之四海而皆准的最优密度，效应方向与强度取决于任务需要多少边界、智能体能承受多少验证负荷。

### 2.3 研究假设

综合上述理论，本研究提出以下假设：

- **H1（全局效应弱化）**：在混合所有任务的完整样本中，约束密度与任务完成率之间不存在显著的全局倒 U 形关系。理由在于，AgentNet 数据中约 93% 的任务不含任何约束关键词，约束密度呈高度零膨胀分布，全局模型会被大量零值稀释，难以检测到统一的曲率。
- **H2（条件倒 U 形）**：在任务难度较高、指令长度较长或包含多个子任务的任务子样本中，约束密度与完成率呈显著倒 U 形关系。此时约束的边界收益与验证成本之间的权衡最为明显。
- **H3（子类型异质性，探索性）**：不同约束子类型（禁止型、保留型、要求型、限制型）的最优密度可能存在差异。例如，禁止型约束可能因直接排除动作而具有较低的过载阈值；要求型约束则可能因强制特定动作而更易引发冲突。该假设为探索性，因各子类型样本量较小。
- **H4（任务难度调节）**：任务难度显著调节约束密度的二次效应，即二次项与任务难度的交互项为负且显著。难度越高，约束密度的倒 U 形曲率越强。

需要强调的是，H1 并非否定约束的价值，而是否定“存在一个适用于所有任务的统一最优密度”。H2 与 H4 才是本研究的理论核心，即约束密度何时成为负荷取决于任务情境边界。

## 3. 研究方法

### 3.1 数据来源与样本

本研究使用 AgentNet 公开数据集的预处理版本（Zhang et al., 2024）。原始样本包含 22,811 条 GUI 任务轨迹。经完整案例分析（listwise deletion）后，主模型纳入 20,484 条任务。其中，指令文本中包含至少一个约束关键词的原始任务为 1,465 条（占 6.42%），进入回归模型的约束任务为 1,261 条（因部分任务在控制变量上存在缺失值）。因变量为二值变量 `task_completed_num`（1 = 完成，0 = 未完成）。

AgentNet 数据的一个重要特征是任务完成状态由轨迹层面的执行结果决定，而非用户主观评价。完成率因此反映的是“智能体是否达成了指令所描述的目标状态”。这一测量方式与实验研究中由人工标注的完成标准存在差异，结论外推时需谨慎。

### 3.2 约束词分类与密度操作化

参考语用学中情态、言外之力与限定表达研究，本研究将约束表达划分为五类（见表 1）：禁止型（C1）、保留型（C2）、要求型（C3）、限制型（C4）以及混合型（C5，同时包含两类及以上约束）。关键词匹配采用 Python 正则表达式，按不区分大小写、词边界方式匹配；短语优先于单词计数以避免重复（例如 “do not” 先被计数，其后的 “not” 不再单独计数）。

约束密度（`constraint_density`）定义为约束词绝对频次除以指令词数再乘以 100，以百分比表示；约束丰富度（`constraint_richness`）定义为同时出现的不同约束类型数（0–4，混合型自然计为 ≥2）。

**表 1 约束表达的类型学定义与关键词**

| 类型 | 定义 | 关键词 |
|------|------|--------|
| C1 禁止型 | 禁止某些操作或行为 | don't, do not, never, avoid, without, cannot, should not, must not |
| C2 保留型 | 要求保持/保留某状态 | keep, maintain, stay, preserve, leave |
| C3 要求型 | 要求必须完成某事 | must, should, need to, have to, required |
| C4 限制型 | 限定范围、对象或方式 | only, just, merely, exclusively |
| C5 混合型 | 同时包含两类及以上约束 | — |

### 3.3 分析策略

#### 3.3.1 三阶段建模框架

为回答“约束何时成为负荷”，本研究采用以下三阶段分析框架：

**Stage 1：约束有无效应**。估计模型：

$$
\text{logit}(P(\text{完成})) = \beta_0 + \beta_1 \cdot \text{has\_constraint\_words} + \gamma \cdot \text{task\_difficulty} + \delta \cdot \text{word\_count} + \eta \cdot \text{os}
$$

该阶段回答“约束是否存在”的二元价值。

**Stage 2：约束密度在约束任务内的全局效应**。将样本限制为包含至少一个约束词的任务（*N* = 1,261），估计二次 Logit 模型：

$$
\text{logit}(P(\text{完成})) = \beta_0 + \beta_1 \cdot \text{density} + \beta_2 \cdot \text{density}^2 + \gamma \cdot \text{task\_difficulty} + \delta \cdot \text{word\_count} + \eta \cdot \text{os}
$$

若 $\beta_2 < 0$ 且显著，则支持倒 U 形假说。拐点由 $-\beta_1 / (2\beta_2)$ 计算，并使用 Delta 法估计 95% 置信区间。

**Stage 3：条件模型**。通过交互项与分样本模型考察任务难度、指令长度、子任务数量等情境变量的调节作用。模型形式为：

$$
\text{logit}(P(\text{完成})) = \beta_0 + \beta_1 \cdot d + \beta_2 \cdot d^2 + \beta_3 \cdot M + \beta_4 \cdot dM + \beta_5 \cdot d^2M + \text{controls}
$$

其中 $d$ 为约束密度，$M$ 为调节变量。分样本模型按调节变量的中位数或二分取值分别估计二次 Logit。

#### 3.3.2 辅助检验

为增强推断稳健性，进一步采用 Dawson（2014）U 形检验判断密度观测区间两端斜率是否符合倒 U 形预期；使用 Cohen's $f^2$ 评估二次项的解释增量；并以绝对频次、丰富度、限制性立方样条（Restricted Cubic Spline, RCS）及操作系统分样本进行稳健性检验。模型比较以 AIC/BIC 与 McFadden 伪 $R^2$ 为准则。

### 3.4 数据特征与测量有效性说明

#### 3.4.1 观测性数据的局限性

本研究使用的是观测性轨迹数据，而非随机化实验。用户是否在指令中加入约束、加入多少约束，可能与其对任务难度的先验判断、领域知识、表达能力乃至应用类型相关。这些未观测因素可能同时影响指令措辞与任务完成率，从而形成内生性问题。因此，本文报告的所有效应均应解读为统计关联，而非因果效应。未来研究可通过控制实验或工具变量方法进一步验证。

#### 3.4.2 规则式约束检测的有效性

约束识别基于关键词规则，具有可解释性与可重复性，但也存在局限。其一，规则方法无法识别隐含约束或复杂否定（例如“我希望结果不要太大”中的“不要”虽可被识别，但“请确保不超出预算”若未出现关键词则会被遗漏）。其二，同一关键词在不同语境中可能承载不同语用功能（例如 “just” 既可是限制词，也可是语气副词），规则匹配会产生一定误判。其三，约束密度以词数做分母，对于极短指令（如 5 个词）中的一次约束会给出 20% 的极端密度值，需在解读时加以注意。尽管存在上述局限，规则检测在现有大规模标注数据稀缺的条件下仍是一种可行且透明的方法；高密度观测的稀缺性（95% 分位数为 1.74%）也意味着极端值对整体推断影响有限。

### 4.2 Stage 1：约束有无效应

表 4 报告了 Stage 1 模型结果。在控制任务难度、指令长度与操作系统后，`has_constraint_words` 的回归系数为 0.152（OR = 1.165，95% CI [1.075, 1.262]，*z* = 3.713，*p* < 0.001）。这表明，在完整样本中，包含至少一个约束词的指令与更高的任务完成率存在显著正相关；平均而言，包含约束词的指令对应的完成几率比不含约束词的指令高约 16.5%。该结果确立了约束表达在整体上的预测价值，但并未说明约束密度的剂量效应。

### 4.3 Stage 2：约束任务内的密度效应（全局弱化）

### 4.4 Stage 3：条件模型——任务难度、指令长度与子任务数量

#### 4.4.1 任务难度的调节作用

表 5 报告了交互效应模型与分样本二次模型结果。在交互模型中，约束密度二次项与任务难度的交互项显著为负（*b* = –0.0091，*p* = 0.019），而密度线性项与难度的交互项不显著（*b* = 0.036，*p* = 0.180）。这表明任务难度显著调节约束密度的曲率，而非简单调节其线性斜率。

按任务难度中位数（6）分样本后，高难度任务子样本（*N* = 8,413）的二次项显著为负（*b*₂ = –0.039，*p* = 0.019），拐点约 1.93%（95% CI [1.03, 2.82]）；低难度任务子样本（*N* = 12,071）的二次项不显著（*b*₂ = 0.007，*p* = 0.218）。该结果支持 H2 与 H4。

#### 4.4.2 指令长度的调节作用

按词数中位数（30）分样本后，长指令任务子样本（*N* = 10,211）呈现显著倒 U 形（*b*₂ = –0.041，*p* = 0.025），拐点约 1.69%（95% CI [0.85, 2.52]）；短指令任务子样本（*N* = 10,273）的二次项不显著（*b*₂ = 0.008，*p* = 0.212）。长指令与高密度约束叠加时，信息稀释与验证负荷效应更加明显。

### 4.7 探索性过程结果：冗余步数比的非线性模式

作为机制探索，本研究进一步以总步数（负二项回归）与冗余步数比（OLS）为结果变量。总步数的二次项不显著（*b* = 0.00010，*p* = 0.915）。冗余步数比则呈现显著倒 U 形（*b*₂ = –0.00038，*p* = 0.012），中等约束密度时冗余探索最多。该结果提示约束密度可能通过“探索—验证”权衡影响执行效率：低密度时智能体缺乏方向而探索不足（或随机探索），中密度时约束引发了更多定向但未被验证的探索，高密度时约束过于严格导致探索被压缩。尽管该发现为机制解释提供了线索，但因属于观测性探索分析，不宜做过强因果推断。

## 5. 讨论

### 5.1 从“全局定律”到“边界条件”

本研究最重要的理论贡献在于将“约束密度是否最优”这一问题从“寻找普适定律”转向“识别边界条件”。整体样本与约束任务子样本均未发现显著的全局倒 U 形效应，这与“过犹不及”假说的直接推论不一致。然而，调节效应分析揭示了一个关键边界：只有在高难度任务、长指令任务或多子任务任务中，约束密度才表现出显著倒 U 形。这一发现支持了本研究的核心论点——约束是一种条件性资源，其效应取决于智能体所面临的规划与验证负荷。

从认知负荷视角看，简单任务本身信息需求较低，额外约束带来的收益有限但成本亦低；复杂任务需要更多指引，但过量约束可能迅速超出智能体的规划容量，与性能下降相伴随（Schatz, 2003; Goedert et al., 2013）。关联理论则进一步解释为何长指令任务对高密度约束更敏感：在信息总量已经较大的情况下，新增约束的边际语境收益递减，而加工成本递增（Sperber & Wilson, 1995）。

### 5.2 低、中、高约束密度的作用机制

- **低密度（< 1%）**：约束提供的信息边界不足，智能体需要在较大动作空间中搜索，容易产生偏离目标的探索。Stage 1 结果显示，完全不含约束词的指令完成率显著较低，印证了边界缺失的代价。
- **中密度（约 1.7%–1.9%）**：对于复杂任务，该区间可能是约束收益最大化的“甜蜜点”。此时约束足够多，能够压缩动作空间、澄清目标；但又未多到引发严重冲突与验证负荷。高难度、长指令与多子任务任务的拐点均落在 1.7%–1.9% 附近，显示出惊人的一致性。
- **高密度（> 2%–3%）**：约束数量超出智能体的有效处理能力。规划模块需要在大量约束下搜索可行路径，验证模块需反复检查每一步是否违规，冲突消解模块需处理相互矛盾的约束。最终表现为完成率下降。

### 5.3 子类型异质性的可能解释

子类型分析未发现显著差异，主要原因可能是统计功效不足。各子类型的非零案例仅为 224–459 条，且混合型任务的存在使得单一类型的独立效应难以识别。此外，规则式关键词匹配无法捕捉同一类型内部的语义强度差异（例如 “must” 与 “should” 的强制程度不同）。未来研究可引入大语言模型进行更精细的约束语义角色标注（如约束对象、动作、条件），以重新检验子类型异质性。

### 5.4 实践建议

基于研究发现，我们对任务型交互智能体的提示工程提出以下实践建议：

1. **高难度任务**：将约束密度控制在 1.7%–1.9% 左右。避免在已经复杂的任务中堆砌过多否定词、限定词或强制词。
2. **长指令任务**：鉴于信息稀释效应，长指令中的约束应更精练，优先保留与核心目标直接相关的约束，删除冗余修饰。
3. **多子任务任务**：每个子任务可单独给出关键约束，但全局层面的约束密度仍应控制在 1.7%–1.9% 附近。
4. **简单任务**：约束密度的容忍区间较宽，但仍需避免极端高密度（如 > 5%），以防产生不必要的验证负荷。
5. **接口设计**：可在用户输入指令后提供约束密度反馈，对高密度提示给出精简建议，尤其针对高难度或长任务。

### 5.5 局限与未来方向

本研究存在以下局限：

1. **约束检测的规则性**：基于关键词的规则方法无法识别隐含约束、复杂否定与语义强度差异，可能引入测量误差。
2. **观测性设计**：无法排除任务领域、应用类型、用户能力等未观测混淆；所有效应均为关联性。
3. **高密度观测稀缺**：95% 分位数仅为 1.74%，限制了对高密度区间曲率的统计功效。
4. **模型收敛问题**：RCS 3 节点模型未收敛，提示在零膨胀稀疏数据上复杂非参数方法的应用需谨慎。

未来研究可从以下方向拓展：

- 使用大语言模型进行更精细的约束语义抽取与人工校验；
- 开展控制实验，随机分配不同约束密度以验证因果关系；
- 构建中介模型，检验冗余步数、验证步数是否在密度与完成率之间发挥中介作用；
- 在多模态智能体（结合视觉与语言）与机器人任务中验证结论的跨边界适用性。

## 6. 结论与展望

本研究基于 AgentNet 大规模 GUI 轨迹数据，系统考察了用户指令中约束密度对任务完成率的非线性影响。主要结论如下：

1. 在完整样本中，包含约束词与任务完成率存在显著正相关（OR ≈ 1.165），表明约束表达整体上具有预测价值。
2. 在约束任务子样本中，不存在稳健的全局倒 U 形密度效应；约束密度的二次项不显著。
3. 任务难度、指令长度与任务子任务数量显著调节约束密度的效应：在高难度、长指令或多子任务情境下，约束密度呈现显著倒 U 形，最优密度集中在 1.7%–1.9% 附近。
4. 冗余步数比在中等密度时达到峰值，暗示约束密度可能通过探索—验证权衡影响执行效率。

本研究的理论意义在于将“约束密度最优”问题重新界定为“约束何时成为负荷”的边界条件问题。实践意义在于为提示工程提供了可量化的密度参考区间。未来研究可在更大规模、更高质量标注数据的基础上，进一步探索约束的语义角色、因果机制与跨任务泛化能力。
