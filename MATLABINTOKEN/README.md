# AgentNet人机交互实证研究

## 论文题目
《自然语言任务表达的操作显性度与GUI智能体协同效能——基于AgentNet交互轨迹的实证研究》

## 项目概述
本研究使用AgentNet公开数据集进行二次分析，探讨用户自然语言任务表达的操作显性度与GUI智能体协同效能之间的关系。

## 数据边界
本研究严格遵守以下限制：
- 不调用任何大模型推理API
- 不重新运行GUI智能体
- 不重新采集交互日志
- 只对公开现成数据进行分析

## 研究问题
1. RQ1：用户自然语言任务描述中的操作显性度是否与任务完成率相关？
2. RQ2：操作显性度是否与执行效率评分和人机任务对齐评分相关？
3. RQ3：操作显性度较低的任务是否包含更多错误步骤和冗余步骤？
4. RQ4：错误步骤比例和冗余步骤比例是否在操作显性度与任务完成之间形成统计路径？
5. RQ5：上述关系在不同操作系统、任务领域、应用类型和任务难度下是否稳定？
