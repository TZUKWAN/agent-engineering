# 共享概念框架：显式推理链与任务型交互智能体

## 1. 核心概念界定

### 1.1 任务型交互智能体

沿用前三篇论文的界定，**任务型交互智能体（task-oriented interactive agent）** 指能够根据自然语言任务指令，在可反馈外部环境中执行多步行动，并依据环境反馈进行调整、验证和终止的智能体系统。其核心链路为：

```
用户任务表达 → 任务表征 → 行动规划 → 环境操作 → 反馈修正 → 结果验证 → 执行终止
```

### 1.2 显式推理链

**显式推理链（explicit reasoning chain）** 指智能体在任务执行过程中以文本形式记录的推理序列，通常表现为 `thought`、`reasoning`、`plan`、`reflection`、`<think>` 块或工具调用前后的解释性文本。它至少包含以下一种或多种元素：

- **目标再述**：对用户需求进行复述或细化；
- **子任务分解**：将总目标拆分为可执行的步骤；
- **约束保持**：在推理中提及并维持指令中的限制条件；
- **验证意识**：主动提出检查、确认、测试等动作；
- **反馈利用**：引用环境返回或工具结果；
- **自我修正**：发现先前假设或动作不当后调整策略；
- **终止判断**：判断任务是否完成并准备结束。

### 1.3 经验边界

本研究仅分析**可被观察到的文本化推理痕迹**，不声称这些痕迹等同于大模型的真实内部思维过程。具体边界如下：

1. AgentNet 数据中的 `thought` 与 `reflection` 字段是事后生成的轨迹解释，属于**显式推理链文本**，而非模型隐藏状态；
2. 对推理链的分类、特征提取与关系检验，均基于这些文本的表面结构与内容线索；
3. 结论只描述“显式推理链类型与执行指标之间的统计关联”，不推断因果机制，也不声称揭示了模型内部认知过程。

## 2. 显式推理链特征体系

论文四采用以下特征体系对显式推理链进行量化：

| 维度 | 操作化指标 | 说明 |
|------|------------|------|
| 推理长度 | 每任务/每步推理文本字符数、词数 | 反映推理链的总体体量 |
| 结构化程度 | 规划标记（plan/step/goal/first/next/finally）出现次数 | 反映推理的组织形式 |
| 任务分解 | 子任务/步骤相关词频、分解标记数 | 反映目标拆解程度 |
| 约束保持 | 推理文本中约束词出现次数 | 反映对指令约束的记忆 |
| 验证意识 | check/verify/confirm/test/ensure 等词频 | 反映主动验证倾向 |
| 反馈利用 | 引用观察/结果的表达（如 "the screen shows"） | 反映对外部反馈的整合 |
| 自我修正 | 修正/重试/改换策略相关表达 | 反映错误后调整 |
| 终止判断 | 完成/结束/停止相关词在末段的集中程度 | 反映终止判准 |
| 推理—行动对齐 | 动作或工具名称在先前推理中的共现比例 | 反映推理到行动的转化 |

## 3. 提示风险与错误机制框架

论文五在显式推理链框架基础上，进一步考察**用户指令风险特征**如何与**推理错误**、**执行错误**及**任务失败**形成观察性统计路径：

```
提示风险特征 → 推理错误指标 → 执行错误指标 → 任务失败
```

- **提示风险特征**：从用户指令文本中提取的、可能增加智能体理解困难的语用属性；
- **推理错误指标**：基于显式推理链文本与任务信息计算的推理偏差代理指标；
- **执行错误指标**：基于轨迹步骤中的 `last_step_correct`、`last_step_redundant` 等字段计算的过程错误代理指标；
- **任务失败**：任务级结果变量 `task_completed = False`。

上述路径仅为**观察性统计路径**，用于描述变量之间的预测关系与过程证据，不构成因果证明。

## 4. 数据来源与一致性说明

本组论文四与论文五均以 **AgentNet（xlangai/AgentNet）** 为主要数据来源，理由如下：

- 与前三篇论文共享同一数据集，变量定义保持一致；
- 同时包含用户指令文本、任务级完成标签、步骤级正确/冗余标签以及显式推理链文本；
- 允许在统一的任务样本上同时构建提示风险、推理错误与执行错误指标。

论文四也可以接受其他包含 `<think>` 或 reasoning trace 的公开数据集（如 `lambda/hermes-agent-reasoning-traces`）作为补充，但所有统计结果必须在说明变量不可直接混合的前提下统一处理。本实现阶段以 AgentNet 为主，确保结果可复现且不依赖外部 API。

## 5. 与前三篇论文的关系

| 论文 | 关注链路 | 核心新增概念 |
|------|----------|--------------|
| Paper 01 | 结果验证 → 执行终止 | 验证显性度 |
| Paper 02 | 行动规划 → 环境操作 | 约束密度 |
| Paper 03 | 用户任务表达 → 任务表征 | 语用结构类型 |
| **Paper 04** | 任务表征 → 行动规划 | **显式推理链类型** |
| **Paper 05** | 用户任务表达 → 推理错误 → 执行错误 → 任务失败 | **提示风险与错误路径** |

论文四与论文五在理论上承接前三篇论文的“任务型交互智能体”概念，但聚焦智能体侧的显式推理过程及其失败路径，构成一个新的分析层次。
